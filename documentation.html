📖 Introduction

Syntaxa IA est un assistant de développement intelligent propulsé par OpenAI. Il vous aide à coder plus vite, débugger plus efficacement et apprendre de nouvelles technologies.

✨ Ce que Syntaxa IA peut faire :
  • Générer du code dans tous les langages populaires
  • Débugger et corriger les erreurs
  • Expliquer des concepts complexes
  • Optimiser votre code existant
  • Répondre à vos questions techniques

🚀 Démarrage Rapide

Pour commencer à utiliser Syntaxa IA, suivez ces étapes simples :

Étape 1 : Obtenir une clé API OpenAI

  1. Créez un compte sur platform.openai.com
  2. Accédez à la section "API Keys"
  3. Créez une nouvelle clé secrète
  4. Copiez et sauvegardez votre clé (elle commence par "sk-")
⚠️ Important : Ne partagez jamais votre clé API publiquement. Gardez-la confidentielle et sécurisée.

Étape 2 : Configurer Syntaxa IA

  1. Ouvrez l'interface de chat
  2. Dans la barre latérale, localisez le champ "Clé API OpenAI"
  3. Collez votre clé API
  4. La clé est sauvegardée automatiquement dans votre navigateur

Étape 3 : Commencer à utiliser

C'est tout ! Vous pouvez maintenant poser vos questions ou demander de générer du code.

🔑 Configuration API

Modèles Disponibles

Syntaxa IA supporte plusieurs modèles OpenAI :

  • GPT-4 Turbo : Le plus avancé, idéal pour les tâches complexes
  • GPT-4 : Très performant pour la plupart des tâches
  • GPT-3.5 Turbo : Rapide et économique pour les tâches simples
💡 Astuce : Utilisez GPT-3.5 Turbo pour les questions simples et GPT-4 Turbo pour les tâches complexes nécessitant plus de réflexion.

Gestion des Coûts

L'utilisation de l'API OpenAI est payante. Les coûts varient selon le modèle utilisé. Consultez la page de tarification OpenAI pour plus de détails.

❓ Questions Fréquentes

Syntaxa IA stocke-t-il mes conversations ?

Non, toutes les conversations sont stockées localement dans votre navigateur. Seules les requêtes à l'API OpenAI sont transmises, et OpenAI ne conserve pas vos données si vous utilisez votre propre clé API.

Puis-je utiliser Syntaxa IA sans connexion internet ?

Non, une connexion internet est nécessaire pour communiquer avec l'API OpenAI.

Quelle est la limite de tokens ?

Syntaxa IA est configuré pour utiliser jusqu'à 2000 tokens par réponse. Cela permet d'obtenir des réponses détaillées tout en maîtrisant les coûts.

Comment puis-je sauvegarder mes conversations ?

Utilisez le bouton "📋 Copier" dans l'en-tête du chat pour copier toute la conversation dans votre presse-papier.

Syntaxa IA peut-il exécuter du code ?

Non, Syntaxa IA génère uniquement du code. Il ne l'exécute pas. Vous devez copier le code et l'exécuter dans votre environnement de développement.
